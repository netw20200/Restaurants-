MAISON — MODERN RESTAURANT HTML TEMPLATE
========================================
Version 1.0.0

A premium responsive HTML5 template for restaurants, fine dining venues,
cafes, steakhouses and hospitality businesses.

FEATURES
- Responsive HTML5/CSS3/JavaScript
- Light premium design
- Mobile navigation
- AOS scroll animations
- Hero, About, Signature Dishes, Menu, Chef, Experience, Gallery,
  Testimonials, Reservation and Contact sections
- Favicon and theme color
- Google Fonts

FILES
index.html — main page
style.css — main stylesheet
script.js — navigation, AOS and demo reservation form
images/ — demo visual assets

CUSTOMIZATION
Edit the text, prices, address, phone, email and links directly in index.html.
Replace the demo SVG images in images/ with the buyer's own photography.
Keep the same filenames to avoid changing HTML paths.
The reservation form is front-end demo only and must be connected to a
booking service or backend before production use.

DEMO IMAGES
The included SVG visuals are DEMO PLACEHOLDERS created for template preview.
They should be replaced with the buyer's own restaurant photography.

DEPENDENCIES
Google Fonts: https://fonts.google.com/
AOS: https://michalsnik.github.io/aos/
These are loaded from public CDNs.
